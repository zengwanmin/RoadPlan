# 走廊带 DEM 数据说明（`走廊带DEM_z14_ext.npz`）

本文件为 `opt` 分支新增的数字高程模型（DEM）栅格，**仅供图C9（全图层叠加）作地形底图**，
不参与本分支的目标函数计算（本分支 `objective.py` 的地面高程取自 `数据.xlsx` 实测高程）。

## 数据来源

- 数据源：**AWS Terrain Tiles**（terrarium 编码，公开免密钥），缩放级 `z = 14`
- 覆盖范围：`lon 113.159 ~ 113.423`，`lat 23.095 ~ 23.201`
  （实测线位外扩约 2.8 km，支撑 ±2.5 km 走廊带）
- 拼接：60 张瓦片 → `1280 × 3072` 栅格；本纬度（23.16°N）约 **8.8 m/像素**
- 高程解码：`h = R·256 + G + B/256 − 32768`（terrarium 规范）
- 坏点处理：`< −100 m` 的像素已按邻域中值填补；绘图时仍会再次过滤

## 文件字段

| 键 | 含义 |
|---|---|
| `elev` | 高程栅格（float32, 1280×3072, 单位 m, 现状地表） |
| `z` | 瓦片缩放级（14） |
| `x0`, `y0` | 栅格左上角对应的瓦片索引 |
| `H`, `W` | 栅格行列数 |

像素中心 → 经纬度按 Web Mercator 瓦片公式反算，再用与 `data_loader.load_alignment`
**相同**的局部平面投影换算到模型笛卡尔坐标（见 `优化方案对比（平面、纵断面联合协同优化）/alllayers.py`
中的 `_dem_grid_xy`）。

## 与实测高程的一致性

沿实测中线采样 DEM 与 GPS 实测高程：相关系数 **0.915**，中位偏差 **+1.57 m**
（DEM 为正高、GPS 为高程，垂直基准差以常数偏置消除）。

## 说明

- 该栅格为**现状地表**，既有北环路基已包含在内。`main` 分支另有
  `走廊带DEM_z14_ext_natural.npz`（移除道路影响带后的准天然地面）用于统一土方计费口径；
  本分支不需要该派生文件，故未收录。
- 许可：AWS Terrain Tiles 汇集 SRTM、NED 等公开数据源，详见
  https://registry.opendata.aws/terrain-tiles/
