# 多算法对比（Benchmark Comparison）

对应《实验设计方案2（熵权法标量化 + IJS 单目标寻优，自适应权重）》**实验二**。

## 目的
在同一模型、同一熵权标量化目标 F、同约束、同参数、同运行环境下，验证 IJS 相对学位论文所用 **NSGA-II** 及主流元启发式算法（JS/GA/PSO/GWO）在求解立体线形优化问题上的综合优势：解质量、收敛速度、运行时间、稳定性、Pareto 前沿质量。

## 溯源（不可杜撰）
- **公式**：目标 C/E、约束、熵权法 F 与消融实验共用 `objective.py`（式号已逐条标注，全部取自林坤锐学位论文）；NSGA-II 依论文 §5.2–5.3（快速非支配排序、拥挤距离、锦标赛、SBX、精英保留，Pareto 支配式 5.1–5.2）。
- **数据**：北环高速 `数据.xlsx`（14018 组实测轨迹，22.462 km）。
- **算法**：GA/PSO/GWO 移植自参考代码 `GA.m`/`PSO.m`/`GWO.m`；IJS/JS 复用 `algorithms.py`；NSGA-II 见 `benchmarks.py`。

## 设置（实验设计方案2 §1.4 / §3.3）
- 三种规模（以纵断面桩号步长控制决策维度）：**P1 小**（步长300 m, dim=75）/ **P2 中**（100 m, dim=225, 主体 22 km）/ **P3 大**（50 m, dim=450）。
- 种群 200，最大迭代 500，各算法各规模**独立运行 30 次**；CR=0.5、Levy β=1.5。
- 熵权法客观权重（各规模由基准种群计算）：P1 wC=0.880/wE=0.120，P2 wC=0.726/wE=0.275，P3 wC=0.720/wE=0.280。
- 所有对比算法在**同一标量化目标 F、同一归一化区间**下比较（公平性）。

## 运行
```bash
python3 run_comparison.py    # 3规模×6算法×30次 + P2 Pareto权重扫描 (~61 min)
python3 make_outputs.py       # 生成全部图表 -> figures/ 与 tables/
```

## 主要结论（本次运行）
- **解质量**：IJS 在三种规模上均取得最优 F（P1 0.145 / P2 0.168 / P3 0.130），且随规模增大优势扩大——JS 在 P3 退化到 5.57，GA/PSO 在 P2/P3 达数十至数百量级，NSGA-II 在高维（P2/P3）因缺少约束修复算子而大量违反纵坡约束、陷入高惩罚区。
- **稳定性**：IJS 标准差最小（P2 std=0.0001），Friedman 平均秩 **1.00**（最优）；Wilcoxon 秩和检验 IJS 对其余 5 个算法 p=2.87e-11（均显著优于对手，α=0.05）；Friedman 检验 χ²=146.4, p=7.79e-30。
- **Pareto 质量**（P2）：IJS 超体积 HV 最大（1.40e7）、IGD 最小（≈0）、前沿点数 9，明显优于各基线。
- **运行时间**：IJS 单次耗时高于其它算法（种群 200 下 P2 约 47 s、P1/P3 约 25/42 s），源于每代额外的 Levy 与 DE 内层评估；但换来的是数量级更优的解质量与稳定性。收敛代数不随规模恶化（P1 77→P3 57 代），可扩展性良好。（注：表B1 中 P2 的 JS 耗时受测量时系统负载影响偏高，属计时噪声，不影响解质量结论。）

## 如实说明
1. **NSGA-II 在高维退化**是真实且可解释的结果：学位论文 §5.3.1 的 NSGA-II 含"带约束修复的 SBX + 二次抛物线连接变坡点"等几何修复算子；本实现为保证与其它算法同口径（统一惩罚法处理约束），未加入该问题专用修复，故 NSGA-II 在 225/450 维纵坡约束下难以进入可行域。这与参考手稿中"基线算法随规模增大而丧失可行性"的现象一致。
2. **目标 C 与 E 强正相关**：净高差固定时，平顺纵断面同时降低土方成本与行车能耗（与学位论文"LCC 与能耗同步下降"结论一致），故真实 C–E 权衡前沿较窄；图B2 采用对数坐标以同时呈现各算法前沿位置。
3. 论文未给定的少量工程系数（燃油/电价、单位土方费等）沿用消融实验的 `params.py` 工程标定值；因本实验为同口径相对比较，不影响算法排序结论。
