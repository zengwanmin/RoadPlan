# 实测数据

项目实测数据，是全项目的**基准**。第三方数据（DEM / OSM）只在实测数据无法覆盖的地方
使用，并且每一处使用都必须给出与实测数据的一致性核验。

## 文件

| 文件 | 内容 |
|---|---|
| `数据.xlsx` | 既有北环高速 GPS 实测中线，**14018 点**，字段 `Latitude / Longitude / Altitude / Distance / R` |
| `北环高速现状桥梁隧道统计.xlsx` | 现状桥梁、隧道长度统计（桥隧计费基准与校准依据） |
| `data_loader.py` | 加载与投影脚本 |

## 坐标投影（全项目统一）

`data_loader.py::load_alignment`，对应论文式 3.3–3.4，以中线**首点**为原点的局部平面近似：

```
lat0, lon0 = 首点纬经度(弧度)          # 23.15442°N, 113.38835°E
X = R_E · cos(lat0) · (lon − lon0)     # 东向, m
Y = R_E · (lat − lat0)                 # 北向, m
R_E = 6378137.0                        # WGS84 长半轴
```

**DEM 栅格像元、OSM 折线顶点、建筑轮廓顶点全部按这同一公式换算**到该局部坐标系
—— 这是各图层能够正确叠合的前提。绘图脚本中都写有包围盒自检，
一旦投影原点不一致会直接报错，而不是画出一张错位的图。

## 里程方向（读图必知）

中线首点位于走廊带**东端**，即**累计里程 0 在东侧（黄村端）**，里程沿东→西增长。
论文表中给定的立交**名称**与实际地理位置呈**东→西反序对应**
（详见 `../osm/obstacles/README.md`）。不影响计算，但影响读图。

## 实测数据的模型用途

| 字段 | 用途 |
|---|---|
| `Latitude` / `Longitude` | 基准平面线位；局部投影原点；走廊带中心线 |
| `Altitude` | 现状纵断面地面高程；DEM 垂直基准校核（相关系数 0.915、中位偏差 +1.57 m） |
| `Distance` | 累计里程，纵断面桩号轴 |
| `R` | 平面曲线半径，最小半径约束（R ≥ 400 m）与曲率能耗项 |
