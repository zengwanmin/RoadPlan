# 当前模型平纵协同结构消融

基准为主确认性实验中前 10 个 `V5_IJS` 联合 273 维结果。使用同一固定端点、DEM/OSM、密度启用目标、同一冻结熵权、同一强惩罚和同一初始种群投影，补跑：

- `plan_only`：只优化 50 个平面模态，纵断面固定为 M-A；
- `profile_only`：平面固定为 M-A，只优化 223 个坡度对比坐标；
- `sequential`：先以 300,000 NFE 优化平面，再固定所得平面并以 300,000 NFE 优化纵断面。

单独两类各使用 600,000 NFE；顺序方案两阶段合计恰为 600,000 NFE。所有方法使用 IJS 与配对算法种子；阶段二使用预注册的 `seed+1`。最终相对联合方案作配对 Wilcoxon、Holm（三个比较）、配对秩二列效应量和 20,000 次 bootstrap CI。

结构消融回答“在当前模型和相同总预算下，同时搜索是否优于冻结另一子空间或顺序冻结”，不等同于证明联合搜索在所有预算分配下全局占优。
