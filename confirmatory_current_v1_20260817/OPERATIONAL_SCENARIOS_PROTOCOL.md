# 当前模型运营情景评估

该分析在主确认性实验之后执行，不参与优化器选择，也不计为额外搜索 NFE。对 20 个 `V5_IJS` 最终线位和同一个 M-A 基准，在当前固定端点、DEM/OSM、密度启用模型上重算：

- 基准：EV 30%，交通量和能源价格不额外增长；
- EV 占比 10%、50%；
- 年交通增长 2%、4%；
- 年燃油价格增长 2%；
- 年电价增长 2%；
- 油电价格同时年增 2%；
- 燃油车节油 10%；
- 电动车节能 10%。

输出每个情景下 20 个线位相对 M-A 的 C/E 改善分布和配对 bootstrap 95% CI。该分析描述既得设计的条件响应；不得写成“各情景均经重新优化”，也不替代空间/工程参数的 8 场景重优化。
