# 消融实验（Ablation Study）

对应《实验设计方案2（熵权法标量化 + IJS 单目标寻优，自适应权重）》**实验一**。

## 目的
验证改进水母搜索算法 IJS 相对原始 JS 引入的三大改进组件——**Tent 混沌映射初始化、Levy 飞行、差分进化（DE）**——各自及组合对求解性能（解质量、收敛速度、稳定性、运行时间）的独立贡献。

## 溯源（不可杜撰）
- **公式**：全生命周期成本 C（式3.41–3.55）、土石方 C_TU（式4.3）、燃油车油耗 E_fuel（式4.5–4.12）、电动车能耗 E_ele（式4.13–4.18）、双目标 C/E（式4.25–4.26）、约束（式4.27–4.29）、熵权法 F（式5.3–5.4），全部取自林坤锐学位论文，出处已在 `objective.py` / `params.py` 逐条标注。
- **数据**：北环高速公路车辆 GPS 轨迹 `数据.xlsx`（14018 组有效样本，路段实测 22.462 km，地面高程 −4.7~67.23 m）。经度纬度→平面坐标、里程与地面高程剖面由 `data_loader.py` 按论文 §3.3 生成。
- **算法**：`algorithms.py` 移植自参考代码 `js.m` / `IJS.m` / `levy.m`，三组件做成开关以构成 5 个变体。
- 论文表中标注"由工程实际确定"而未给具体数值的系数（燃油/电价、单位土方费等），集中列于 `params.py` 的工程标定区并注明；因消融实验为同一目标函数下 5 变体的相对比较，绝对标定值不影响结论。

## 统一设置（实验设计方案2 §1.4）
种群 200，最大迭代 500，独立运行 30 次；CR=0.5，Levy β=1.5；熵权法客观权重 wC=0.726 / wE=0.275（由基准初始种群计算）；5 变体在每次 run 内共享同一初始种群，保证公平比较。

## 运行
```bash
python3 run_ablation.py      # 5变体×30次 主实验 (~22 min), 输出 results/ablation_results.json
python3 make_outputs.py      # 生成全部图表 -> figures/ 与 tables/
```

## 主要结论（本次运行）
- **Tent 初始化**贡献最大：V2 相对 JS 基线均值 F 降低 **41.2%**，且标准差从 0.044 降至 0.0002（稳定性剧增），收敛代数从 202 降至 54。
- **DE** 单独贡献次之（V4 提升 28.3%）；**Levy** 单独对本问题增益最小（V3 +3.35%），但配合其他组件与贪婪选择可维持全局探索。
- **完整 IJS（V5）** 取得最优解质量（均值 0.1684）与最优稳定性（标准差 0.0001），验证三组件的协同必要性；代价是运行时间较基线增加（32.9s vs 7.3s，因每代增加 Levy 与 DE 内层评估、且种群规模 200）。
