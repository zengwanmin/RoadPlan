# 消融实验说明与分析总结

> 本文档完全基于 `results/ablation_results.json` 的实际实验结果撰写，所有数值均来自 30 次独立运行的统计输出，未做任何主观修饰或杜撰。公式与参数溯源见 `objective.py`、`params.py`（均取自林坤锐学位论文），数据来自北环高速实测轨迹 `数据.xlsx`。

## 一、实验说明

### 1.1 实验目的

改进水母搜索算法（Improved Jellyfish Search, IJS）在原始水母搜索算法（JS）基础上引入了三个改进组件：**Tent 混沌映射初始化、Levy 飞行、差分进化（DE）**。本消融实验的目的是通过组件"有/无"的正交组合，定量分离每个组件对求解性能的独立贡献，并考察三者的协同效应，从而回答：

1. 每个改进组件是否真正有效？有效性有多大？
2. 哪个组件是主要贡献者？
3. 三个组件组合成完整 IJS 后是否存在协同增益？

### 1.2 优化问题与目标函数

消融实验在同一个高速公路立体线形优化问题上进行。决策变量为纵断面各变坡点高程（维度 dim=225，对应北环高速 22.462 km 路段按 100 m 桩号离散）。双目标经熵权法（式5.3—5.4）标量化为综合系统效益：

**F = w_C · C_norm + w_E · E_norm + 惩罚项**

其中权重由初始种群客观计算得 **w_C=0.7255、w_E=0.2745**；C 为全生命周期成本（式3.41—3.55 + 土石方式4.3），E 为油电混合车流能耗（式4.4—4.18）。能耗 E 采用与成本 C 一致的全生命周期口径（日能耗 × 365 天 × 30 年等额年金现值 5% 折现，与养护费 CQ 同口径），单位亿元，与论文表6.8 能耗单位一致。F 越小越优。（说明：能耗按全周期折算相当于对原日能耗乘同一常数，标量化 F、熵权与最优解均不变，故本口径调整不影响任何消融结论，仅使 E 的展示单位与成本一致。）

### 1.3 变体设计（表A1）

以原始 JS 为基线，按三组件正交组合出 5 个变体：

| 编号 | 变体名称 | Tent初始化 | Levy飞行 | 差分进化DE |
|---|---|---|---|---|
| V1 | JS（基线） | ✗ | ✗ | ✗ |
| V2 | JS + Tent | ✓ | ✗ | ✗ |
| V3 | JS + Levy | ✗ | ✓ | ✗ |
| V4 | JS + DE | ✗ | ✗ | ✓ |
| V5 | IJS（完整） | ✓ | ✓ | ✓ |

### 1.4 统一实验条件

- 种群规模：**200**（表6.5 原文值）；最大迭代次数：500；独立运行次数：**30 次**（消除随机性，支撑统计分析）
- 关键参数：DE 交叉概率 CR=0.5，Levy 稳定分布参数 β=1.5，Tent 参数 μ=2
- 公平性保证：5 个变体在每次独立运行内共享同一初始种群与同一目标函数 F（相同权重、相同归一化尺度 C_ref、E_ref）
- 评价指标：综合效益 F 的最优值/均值/标准差、收敛代数（达到最优解 99% 所需迭代次数）、平均运行时间、相对基线 JS 的提升率

## 三、分析总结

### 3.1 Tent 混沌映射初始化：贡献最大的组件

在三个组件中，Tent 初始化的单独贡献最为突出。对比 V2（JS+Tent）与 V1（JS）：

- **解质量**：均值 F 由 0.2868 降至 0.1686，相对基线提升 **41.24%**，是三个单组件中降幅最大的；
- **稳定性**：标准差由 0.0438 降至 0.0002，缩小约 **203 倍**；30 次运行的极差由 0.1669 收窄到 0.0009，几乎每次都收敛到同一优质解；
- **收敛速度**：收敛代数由 202.3 缩短到 53.5，**加快约 3.8 倍**；
- **可行性**：V2 最优解的约束惩罚为 0，得到完全满足规范的可行方案，而 V1 仍带 3.70×10⁷ 的惩罚；
- **计算代价**：运行时间几乎不变（7.32s→7.26s），即 Tent 初始化以近乎零的额外开销换取了上述全面提升。

从收敛曲线（图A1）可佐证这一点：V2 的曲线起点为 2.012，而 V1/V3/V4 的起点在 91~92 量级——Tent 混沌序列生成的初始种群本身已具有高均匀性和高质量，使算法"起跑线"就大幅领先。这说明在高维（225 维）强约束的线形优化问题中，初始种群的分布质量对最终结果具有决定性影响。

### 3.2 差分进化（DE）：稳健的次要贡献者

对比 V4（JS+DE）与 V1：

- 均值 F 由 0.2868 降至 0.2058，相对提升 **28.25%**，为第二大贡献；
- 标准差由 0.0438 降至 0.0196，缩小约 2.2 倍；收敛代数由 202 缩短到 108（加快 1.9 倍）；
- 最优解惩罚降至 0（完全可行），显著优于 V1 的 3.70×10⁷。

DE 通过个体间差异向量的变异—交叉—选择重组种群信息，增强了局部精细搜索与向可行域收敛的能力，在 pop=200 的较大种群下已能收敛到完全可行域（惩罚=0）。但其单独作用（V4 均值 0.2058）仍明显弱于 Tent（V2 均值 0.1686），且带来一定计算开销（运行时间 7.32s→14.67s）。

### 3.3 Levy 飞行：单独作用有限，需协同发挥

对比 V3（JS+Levy）与 V1：

- 均值 F 由 0.2868 降至 0.2772，相对基线为 **+3.35%**，即单独引入 Levy 飞行带来了小幅正向增益；
- 标准差（0.0384）、收敛代数（190.7）较基线略有改善但幅度很小；运行时间由 7.32s 增至 25.41s；
- 最优解惩罚 2.54×10⁷，仍未完全进入可行域。

这一结果表明：**Levy 飞行的长程随机跳跃单独作用于原始 JS 框架时，仅带来有限的正向增益**（在三组件中贡献最小）——其大步长扰动主要拓宽全局探索，但在缺乏有效局部收敛机制（DE）配合时，难以稳定收敛到可行域，故单独作用远弱于 Tent 与 DE。Levy 的真正价值在与其它组件协同时体现（见 3.4）。

### 3.4 完整 IJS 的协同效应

完整 IJS（V5，三组件齐备）取得全体最优：

- **解质量最优**：均值 F=0.1684，相对基线提升 **41.31%**（略优于 V2 的 41.24%）；最优值 0.1681 为五变体最小；
- **稳定性最优**：标准差 0.0001，为全体最小（约为 JS 的 1/302）；30 次运行极差仅 0.0006；
- **收敛快**：收敛代数 57.7，约为 JS 的 1/3.5；
- **完全可行**：最优解惩罚为 0，对应工程指标 C=0.5775 亿元、E=13.1522 亿元（全周期），为五变体中成本与能耗同时最低。

关于协同效应需客观指出：**V5 相对 V2 的提升幅度很小**（均值 0.1684 vs 0.1686，最优 0.1681 vs 0.1683）。这说明在本问题中，Tent 初始化已将种群带入优质吸引域，解质量的绝大部分增益由 Tent 贡献；Levy 与 DE 在此基础上的边际增益有限，但仍带来两点可观察的改善：（1）标准差进一步由 0.0002 降至 0.0001（稳定性再提升）；（2）最优值 F 再降低约 0.0002。这与"Levy 拓宽搜索、DE 精细重组、二者经中间贪婪选择顺序耦合"的设计机理一致——单独的 Levy（V3）增益有限，但在 Tent+DE 的框架内，Levy 的长程探索被贪婪选择保留有效改进，从而对最终解的稳定性与极值起到锦上添花的作用。

### 3.5 计算代价的权衡

改进组件带来性能提升的同时也增加了计算开销：运行时间由 JS 的 7.32s 依次增至 V5 的 32.85s（主要因每代新增 Levy 与 DE 的内层适应度评估，且种群规模为 200）。但考虑到：（1）高速公路线形优化属于规划设计阶段的离线优化，非实时任务；（2）32.85s 的绝对耗时仍在工程可接受范围；（3）换来的是数量级的解质量与稳定性提升（可行方案 vs 不可行方案），这一计算代价是值得的。

### 3.6 组件贡献排序与结论

综合 30 次独立运行的统计结果，三个改进组件对本高速公路立体线形优化问题的贡献排序为：

**Tent 混沌初始化（+41.24%） > 差分进化 DE（+28.25%） > Levy 飞行（+3.35%，贡献最小、需协同）**

主要结论：

1. **Tent 混沌映射初始化是 IJS 性能提升的核心来源**，以近乎零的计算代价大幅改善解质量、稳定性、收敛速度与可行性，凸显了初始种群质量在高维强约束优化中的决定性作用。
2. **差分进化提供稳健的次级增益**，增强局部精细搜索与向可行域的收敛（在 pop=200 下 V4 已达完全可行）。
3. **Levy 飞行单独增益最小（+3.35%），但在完整框架中通过顺序耦合 + 贪婪选择贡献边际的稳定性与极值改善**，验证了三组件"顺序执行、中间贪婪选择"设计的合理性。
4. **完整 IJS 取得全体最优的解质量（均值 F=0.1684）与最优稳定性（标准差 0.0001），并与 V2、V4 同为完全可行（惩罚=0）的工程方案**，证明了三组件组合的必要性与有效性。

### 3.7 关于数据的客观说明

- 本报告全部数值取自 30 次独立运行的实际统计（`results/ablation_results.json`，种群规模 200、迭代 500），包括最优/均值/标准差/分位数/收敛代数/运行时间/最优解工程指标与约束惩罚。
- V3（JS+Levy）单独作用仅 +3.35%，是三组件中贡献最小的，为真实实验结果，未做修饰；它揭示了 Levy 飞行的价值主要依赖于与其它组件的协同配合，是消融实验的有价值发现。
- V5 相对 V2 的微小差距（而非显著优势）亦为真实结果，如实反映了在本特定问题上 Tent 初始化的主导地位。这提示：在其它地形更复杂、约束更强的路段，Levy 与 DE 的协同增益可能更明显，此点可在后续多案例研究中进一步验证。
- **关于种群规模的说明**：本实验采用学位论文表6.5 原文的种群规模 200。相比 pop=100，较大种群使基线 JS（V1）本身的探索更充分（均值 F 由 0.578 提升至 0.287），因此各改进组件的"相对提升率"数值有所收窄（如 Tent 由 +69.89% 变为 +41.24%）；但三组件的贡献排序（Tent > DE > Levy）与"完整 IJS 取得最优解质量、最优稳定性、完全可行"的核心结论保持不变，表明消融结论对种群规模具有稳健性。
- **关于不与论文表6.8 绝对成本对标的口径说明**：本实验目标函数中桥隧建设费用 CB 缺省为 0，故不以绝对全生命周期成本 C 与学位论文表6.8（约 9.64~10.24 亿元、其中桥隧费为主）直接对标；§2.3 相应聚焦"约束可行性"而非绝对成本。CB=0 的原因是**桥隧费用系数在论文与数据集中均无取值**：（1）学位论文桥隧费用公式（式3.45—3.51）所需的费用系数 a₁~a₄、隧道单位挖方费 K_q、横断面半径 r_q、通风照明等其他费用系数，论文均标注为"由具体工程决定/由工程实际情况决定"，正文与数据文件夹中均未提供具体取值；（2）桥隧的触发（填方净高>30 m 建桥、路堑挖深>30 m 建隧）依赖现状设计纵断面，而论文未公开该数据，本实验数据段（`数据.xlsx`）为白云山南麓缓坡，纵断面优化后填挖<30 m 不触发桥隧，故 CB≈0；（3）论文表6.8 亦注明其"填挖方量为估算值、未考虑横断面设计"。**需强调：消融实验比较的是 5 个变体在【同一目标函数 F】下的寻优性能（相对比较），成本的绝对量级不影响"哪个组件贡献大、谁收敛快、谁更稳定、谁能收敛到可行域"这一类算法结论。** 桥隧费用与论文表6.8 成本量级的复现，属"优化方案对比"实验的范畴（该实验按里程比例计入桥隧综合造价），不在本消融实验目标之内。
