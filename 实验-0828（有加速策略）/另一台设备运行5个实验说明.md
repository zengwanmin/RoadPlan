# 实验-0828（有加速策略）：另一台设备运行说明

本说明用于在另一台设备上直接运行本目录的 5 个正式实验。命令按 60 核设备设计，适用于 Linux/macOS 的 Bash 或 Zsh。

## 一、复制目录与安装环境

必须完整复制整个 `实验-0828（有加速策略）`，尤其不能遗漏根目录的 `数据/`。根目录应包含：

- `数据/`
- `多算法对比/`
- `消融实验/`
- `消融实验_（tent真正作为初始化替代）/`
- `优化方案对比（平面、纵断面联合协同优化）/`
- `敏感性分析（平、纵联合，重优化）/`

推荐 Python 3.10 或 3.11。进入本目录后执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy scipy pandas matplotlib openpyxl numba pillow python-docx
```

以后每次登录设备，先执行：

```bash
cd "/另一台设备上的实际路径/实验-0828（有加速策略）"
source .venv/bin/activate
```

检查关键数据：

```bash
test -s "数据/数据.xlsx"
test -s "数据/走廊带DEM_z14_ext.npz"
test -s "数据/走廊带DEM_z14_ext_natural.npz"
test -s "数据/OSM走廊带障碍物/obstacles.npz"
test -s "数据/OSM走廊带障碍物/ic_anchor_cache.json"
echo "关键数据检查通过"
```

## 二、当前正式配置与预计时间

| 实验 | 当前代码配置 | 60 核预计时间 |
|---|---|---:|
| 多算法对比 | 普通性能 10 次/300 代/PJ1–PJ6；Pareto 10 次/300 代/9 权重/PJ1、PJ3、PJ6 | 12–16 小时 |
| 消融实验 | 8 变体，每变体 10 次、300 代 | 25–35 分钟 |
| Tent 真正初始化消融 | 8 变体，每变体 10 次、300 代 | 25–35 分钟 |
| 优化方案对比 | 联合 1000 代；两阶段各 500 代；包含 40 权重点加密 | 2.5–4 小时 |
| 敏感性分析 | 237 个采样点，每点 1 次、300 代 | 45–90 分钟 |

依次完成约需 16–23 小时，建议预留 24 小时。各子目录旧 README 可能仍有 30 次/500 代的历史文字，正式参数以当前代码和本说明为准。

## 三、运行前的统一设置

建议使用持久终端，避免 SSH 断开导致任务停止：

```bash
tmux new -s experiment0828
```

在 `实验-0828（有加速策略）` 根目录执行：

```bash
export EXP_ROOT="$(pwd)"
export PYTHONUTF8=1
export MPLBACKEND=Agg
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export MKL_NUM_THREADS=1
```

建议在新设备上先做一次冒烟检查（约数分钟，结果写入带 `_smoke` 的独立文件，不覆盖正式结果）：

```bash
(cd "$EXP_ROOT/多算法对比" && python3 -u run_comparison.py --smoke --workers 30)
(cd "$EXP_ROOT/消融实验" && python3 -u run_ablation.py --smoke)
(cd "$EXP_ROOT/消融实验_（tent真正作为初始化替代）" && python3 -u run_ablation.py --smoke)
(cd "$EXP_ROOT/优化方案对比（平面、纵断面联合协同优化）" && python3 -u run_joint.py --smoke --fresh && python3 -u run_twostage.py --smoke --fresh)
(cd "$EXP_ROOT/敏感性分析（平、纵联合，重优化）" && python3 -u run_reopt.py --smoke --workers 30)
```

上述命令全部正常出现 `[完成]` 后，再开始正式实验。

不要同时启动全部实验。按下面四个阶段运行。

## 四、正式运行命令

### 阶段 1：多算法对比

```bash
cd "$EXP_ROOT/多算法对比"
python3 -u run_comparison.py --workers 54 > comparison_formal.log 2>&1 &&
python3 -u make_outputs.py > make_outputs_formal.log 2>&1
```

结果：`results/comparison_results.json`，以及 `figures/`、`tables/`。

### 阶段 2：两个消融版本

两个版本彼此独立，可同时运行；每个版本内部保持串行，以保证运行时间可比较。

```bash
(
  set -e
  cd "$EXP_ROOT/消融实验"
  python3 -u run_ablation.py > ablation_formal.log 2>&1 &&
  python3 -u make_outputs.py > make_outputs_formal.log 2>&1
) &
ABLATION_PID_1=$!

(
  set -e
  cd "$EXP_ROOT/消融实验_（tent真正作为初始化替代）"
  python3 -u run_ablation.py > ablation_formal.log 2>&1 &&
  python3 -u make_outputs.py > make_outputs_formal.log 2>&1
) &
ABLATION_PID_2=$!

wait "$ABLATION_PID_1"
wait "$ABLATION_PID_2"
```

两个目录都应生成 `results/ablation_results.json`、`figures/` 和 `tables/`。

### 阶段 3：优化方案对比与 40 权重点

主链使用 23 个进程，40 权重点使用 30 个进程，可在 60 核设备上同时运行。为了保证 40 权重点确实重新计算，若存在旧缓存，先改名备份：

```bash
export OPT_DIR="$EXP_ROOT/优化方案对比（平面、纵断面联合协同优化）"
if [ -f "$OPT_DIR/results/sweep40_c8c_w500_nodens_freeend.json" ]; then
  mv "$OPT_DIR/results/sweep40_c8c_w500_nodens_freeend.json" "$OPT_DIR/results/sweep40_c8c_w500_nodens_freeend.json.before_rerun"
fi

(
  set -e
  cd "$OPT_DIR"
  python3 -u run_joint.py --workers 23 --fresh > run_joint_formal.log 2>&1 &&
  python3 -u run_twostage.py --fresh > run_twostage_formal.log 2>&1 &&
  python3 -u make_outputs.py > make_outputs_formal.log 2>&1
) &
SCHEME_MAIN_PID=$!

(
  set -e
  cd "$OPT_DIR"
  python3 -u run_sweep40_c8c.py --workers 30 > sweep40_formal.log 2>&1
) &
SWEEP40_PID=$!

wait "$SCHEME_MAIN_PID"
wait "$SWEEP40_PID"
```

核心结果：

- `results/joint_results_w500_nodens.json`
- `results/twostage_results_w500_nodens.json`
- `results/sweep40_c8c_w500_nodens_freeend.json`

预算公平性补充实验已经从代码中移除，不需要运行。

## 七、资源或中断处理

- 内存充足时可使用 54 个 worker；若内存不足或出现交换空间，改为 40 或 30。
- 降低 worker 数只增加运行时间，不改变固定种子的数值结果。
- `run_joint.py`、`run_twostage.py` 支持配置一致时检查点续跑；本文使用 `--fresh` 是为了在新设备上明确执行全新正式实验。
- 40 权重点脚本发现同名结果会直接使用缓存，因此正式重跑前必须按上面的命令备份旧缓存。
- 多算法、消融和敏感性分析中途停止后，应重新执行相应求解命令。
- 不要在求解尚未完成时运行对应的 `make_outputs.py`。
