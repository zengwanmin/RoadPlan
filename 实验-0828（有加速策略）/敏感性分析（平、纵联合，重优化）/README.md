# 敏感性分析（所有点重优化）

对应《实验设计方案2（熵权法标量化 + IJS 单目标寻优，自适应权重）》**实验四**的
**"每点重优化"** 口径版本。

## 与"固定方案"版的本质区别
- 邻目录 `敏感性分析/`（固定方案版）：只优化一次得到 M-C 方案，之后**固定该线形**，
  仅改外部参数、重算 C/E。快，但优化几何不随参数变化。
- 本目录（**重优化版**）：在**每一个参数采样点**上都**重新跑一次完整的平纵联合
  IJS 寻优**（pop=200, iter=500），得到该点真正的最优线形与 C、E、里程、最小半径。
  更贴近工程实际（不同情景下最优设计本就不同），计算量大（207 次 ≈ 2–2.5 h）。

## 四项设计（用户选定：EV 轴加密，共 207 点）
| 项目 | 变量与区间 | 观测（每点重优化） | 论文出处 |
|---|---|---|---|
| ① 交通量增长率 × EV 渗透率 | 交通量 {0,2,4,6,8,10}%；EV {0–100%}（21点） | C、E、L、Rmin | §6.5.1 |
| ② 油价 × 电价 | 油价 {0–5%}、电价 {0–5%}（各6点） | E（及 C、L） | §6.5.2 |
| ③ 节油率 × 电耗降低率 | 节油 {0–5%}、节能 {0–5%}（各6点） | E（及 C、L） | §6.5.3 |
| ④ 目标权重 Pareto 前沿 | w₁ {0.1–0.9}（9点） | 成本–能耗前沿 + 权重分区 + 熵权膝点 | §5.3.4 |

## 溯源（不可杜撰）
- **公式**：全部取自 `林坤锐学位论文.pdf`，复用 `objective.py`/`objective_joint.py`
  （逐式标注式号）。参数化目标 `objective_reopt.py` 已数值验证：默认参数下与
  `objective_joint.objectives_joint` **逐点完全相等（误差 0）**，即只是把 EV 渗透率、
  交通量增长率、油价/电价增长率、节油/节能率由固定值改为可传入，公式本身未改。
  - 车流能耗 E = ω₁·n₁·E_fuel + ω₂·n₂·E_ele（式4.4/4.26），n₁=1−p、n₂=p；
    E_fuel 式4.5–4.12、E_ele 式4.13–4.18；油/电价增长作用于 Kf/ZQ，节油/节能作用于 ml/kwh。
  - 养护费随交通量变化（式3.55）通过 ΔCQ 进入 C；能耗全生命周期折现（365×30年5%年金现值）
    与成本 C 同口径 → 单位**亿元**，与论文表6.8 一致。
  - 桥隧费用按里程综合造价 CB=β·L（β=4.2948e7 元/km）、能耗乘标定系数 k_E=0.6792，与
    "优化方案对比（两阶段/联合）"两实验完全一致，使现状 C/E 命中论文表6.8（10.24/8.95 亿元）、
    本实验基准与优化方案同量级（C≈9.8 亿、E≈8.6 亿）。β、k_E 为论文未给系数的工程标定值
    （见 `params.py` BRIDGE_TUNNEL 与 ENERGY_CALIB 注释）。
- **数据**：`论文与数据资料/论文与数据资料/数据/数据.xlsx`（北环高速 14018 组实测轨迹，
  22.462 km），经 `data_loader.py` 加载，绝不杜撰。
- **算法**：IJS（V5，Tent+Levy+DE），种群 200、迭代 500（用户指定）。

## 文件
| 文件 | 说明 |
|---|---|
| `params.py` `objective.py` `objective_joint.py` `algorithms.py` `data_loader.py` | 自邻目录拷贝、未改，保证本文件夹自包含 |

## 运行
```bash
python3 run_reopt.py            # 正式全量 (pop200/iter500, 207点, ~2–2.5h, 7进程并行)
python3 run_reopt.py --smoke    # 冒烟测试 (iter=5, 17点, 验证管线)
python3 make_outputs.py         # 生成图 D1–D5 与表 D1–D3
```
