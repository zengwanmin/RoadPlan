# 优化方案对比（Scheme Comparison）

对应《实验设计方案2（熵权法标量化 + IJS 单目标寻优，自适应权重）》**实验三**。

## 目的
量化 IJS 求得的立体线形优化方案相对原始人工设计方案的综合改善，并通过三模式分解厘清"成本优化"与"能耗优化"各自的贡献，最后完成边坡稳定性安全验证。

## 三模式（借鉴参考手稿 Mode A/B/C 分解思想）
| 模式 | 名称 | 说明 |
|---|---|---|
| M-A | 现状方案（人工选线） | 依实测地面线、按较粗控制尺度（0.5 km 平滑）设计的纵断面，未做全局精细优化，作为基线 |
| M-B | 单目标成本最优 | 仅以 min C（全生命周期成本）为目标的 IJS 优化（wC=1, wE=0） |
| M-C | 双目标协同最优（本文） | min C 与 min E 协同 + 熵权法决策的 IJS 优化方案 |

**M-B → M-C 差值 = 引入车流能耗协同优化的净贡献。**

## 溯源（不可杜撰）
- **公式**：全生命周期成本 C 及分项 CR/CB/CS/CQ（式3.41–3.55）、土石方 C_TU（式4.3）、能耗 E 及燃油/电动分项（式4.4–4.18）、熵权法（式5.3–5.4）与前两个实验共用 `objective.py`；**边坡失稳危险度 Q = Σ S_u·W_u（式6.1）**，评分等级依表6.7（低1/中3/高5，含地形坡度、沟壑密度、降雨、地质、植被五因素），见 `safety.py`。
- **数据**：北环高速 `数据.xlsx`（14018 组实测轨迹，22.462 km 实测地面高程剖面用作原地面线与纵断面优化基准）。
- **算法**：IJS 复用 `algorithms.py`（种群100，迭代500）。

## 运行
```bash
python3 run_schemes.py     # 计算 M-A/M-B/M-C + 19点权重扫描Pareto解集 (~6 min)
python3 make_outputs.py     # 生成全部图表 -> figures/ 与 tables/
```

## 主要结果（本次运行）
**表C2（M-A → M-C）**：全生命周期成本 **−9.04%**、土石方工程量 **−80.41%**、车流能耗 **−0.33%**、边坡危险度 Q **−3.10%**；建设里程不变。

**表C1（M-B → M-C，能耗协同净贡献）**：引入能耗目标后，车流能耗下降（E_fuel −0.04%、E_ele −0.05%），代价是全生命周期成本小幅上升（+1.09%，主要来自土方 C_TU 为平顺纵坡而增加）。这清晰说明了双目标建模的价值——用极小的成本代价换取行车能耗的持续降低，与参考手稿"B→C change 列"的逻辑一致。

## 如实说明
1. **里程 L 不变、平面线形 M-A=M-C**：本模型（与前两个实验一致）在固定平面线位下优化纵断面（论文式4.24 第4组变量：里程固定优化高程），故里程与平面走向不变。学位论文表6.8 的 7.34% 里程缩短来自平面线位的重新布设（绕避白云山回头曲线），不在本纵断面优化范围内；如需复现该项，需扩展决策变量至平面交点坐标。图C2 因此展示实测平面线位（M-A 与 M-C 平面一致）。
2. **能耗变化幅度较小（−0.33%）**：本研究段为城区平缓地形，净高差固定，纵断面平顺化对以恒定内部功率为主的车流能耗影响为二阶小量，故能耗降幅小于学位论文山区案例的 5.03%——这是真实物理结果，未做人为放大。
3. **安全 Q 的改善来自减少填挖高度**：研究段地面平缓，各方案纵坡均在规范限值内（坡度评分均为低），M-A 因较粗控制尺度产生更多填挖（平均 0.44 m vs M-C 0.09 m），故危险度略高；优化后 Q 由 2.58 降至 2.50。式6.1 中降雨/地质/植被等非地形因素依论文 §6.3（GIS 图件、研究区白云山山区段特征）取分级评分并已在 `safety.py` 标注。
4. 论文未给定的少量工程系数沿用 `params.py` 工程标定值；三模式为同口径相对比较，不影响结论方向。
