# 优化方案对比实验说明与分析总结（平纵断面联合协同优化）

> 本文档完全基于 `results/joint_results.json` 的实际实验结果撰写，所有数值均来自实验输出，未做任何主观修饰或杜撰。公式与参数溯源见 `objective.py`、`objective_joint.py`、`params.py`、`safety.py`（均取自林坤锐学位论文，边坡危险度用式6.1、表6.7），数据来自北环高速实测轨迹 `数据.xlsx`。**本实验的方法是平面线形与纵断面线形的联合协同优化**：三方案 M-A/M-B/M-C 均在同一"平纵一体化"模型下评估与寻优。

---

## 一、实验说明

### 1.1 实验目的

量化 IJS 求得的立体线形优化方案相对原始人工设计方案的综合改善，并通过三模式分解，厘清"单一成本优化"与"成本—能耗协同优化"各自的贡献，最后完成边坡稳定性安全验证。核心问题：（1）平纵联合优化相对现状能带来多大改善？（2）在成本优化之外再引入能耗目标，其净贡献是什么？

### 1.2 三模式设计（均为平纵联合优化）

在同一路段（北环高速 22.462 km）、同一联合决策模型（决策维度 dim=250）、同一技术标准与约束下比较三种方案：

| 模式 | 名称 | 说明 |
|---|---|---|
| M-A | 现状方案（人工选线） | 实测平面中线（法向偏移 δ=0）+ 人工粗放纵断面（0.5 km 平滑地面线），未做全局精细优化，作为基线 |
| M-B | 单目标成本最优 | 平纵联合优化，仅以 min C（全生命周期成本）为目标（w_C=1, w_E=0） |
| M-C | 平纵联合双目标协同（本文） | 平纵联合优化，min C 与 min E 协同 + 熵权法客观决策（w_C=0.674, w_E=0.326） |

**M-B → M-C 的差值即"引入车流能耗协同优化"的净贡献。** 三方案共用同一联合模型：M-A 是该模型下"不优化"的基线，M-B/M-C 是该模型下不同权重的寻优结果。

### 1.3 评价指标（四维）

- 经济：全生命周期成本 C 及分项（工程占地 CR、桥隧 CB、基本建设 CS、养护 CQ，式3.41—3.55）、土石方工程量 C_TU（式4.3）；
- 能耗：油电混合车流能耗 E 及燃油车 E_fuel / 电动车 E_ele 分项（式4.4—4.18），**单位为亿元（全生命周期货币量，与成本 C 同口径）**（见 1.7）；
- 效率：建设里程 L；
- 安全：边坡失稳危险度 Q（式6.1，Q=ΣS_u·W_u，评分依表6.7）。

优化算法为 IJS（V5，含 Tent 初始化 + Levy 飞行 + 差分进化），**初始种群 200、迭代 500**。

### 1.4 平纵断面联合协同优化的机制

学位论文虽在摘要与创新点中宣称"协同优化"，但其正文技术路线实为**分阶段串联**：第3章先单独优化平面线形，第4章"在**确定平面线形的条件下**"再优化纵断面，第6章明确写"平面优化结束后，在实施纵断面优化过程中……"。即论文结果是"平面优化 + 纵断面优化"两步串联的产物，两阶段各自达到局部最优，无法捕捉平纵之间的耦合收益。

本文突破分阶段局限，实现**真正的平纵一体化协同**：把平面走向与纵断面坡度放入**同一决策向量、同一次 IJS 寻优**中同时搜索。

**决策变量**（维度 dim = N_CTRL + M_PROF = 25 + 225 = 250）：一个决策向量 x∈[0,1]²⁵⁰ 同时编码两部分——

- **平面部分** x[0:25]：沿实测线位等弧长布设的 **25 个平面控制点的法向偏移** δ_k。映射关系 δ_k = (x_k − 0.5)·2W，走廊带半宽 W=800 m，即 δ_k∈[−800, +800] m；偏移后的控制点经三次样条平滑生成新平面线形（式3.1—3.4 计算里程与坐标），起终点固定不变。
- **纵断面部分** x[25:250]：沿**新平面线位**等弧长布设的 **225 个变坡点高程**调整。映射关系 H_i = z_ground(i) + (x_i − 0.5)·2·A（A 为允许调整幅度，取地面起伏范围的 0.6 倍且不小于 10 m）。

**协同的关键**在于二者的耦合：平面偏移改变线位走向后，(1) 里程 L 随之改变，直接影响随里程计算的工程占地 CR、基本建设 CS 等成本；(2) 各变坡点是沿**新线位**重新等分布设的，其地面高程取新点位最近实测中线点的地面高程（cKDTree 最近邻，见 3.8 节数据口径声明），因而纵断面的填挖与坡度也随平面走向联动变化。二者在同一目标函数中同时被评估、同时被寻优，实现"里程—土方—坡度—能耗"的一体化权衡。

### 1.5 目标函数与约束（公式）

**双目标**（与论文式4.25—4.26 一致，均按"新里程、新桩号"计算）：

- 目标一 全生命周期成本（式4.25、3.41）：

  C = C_PING + C_TU
  C_PING = CR + CB + CS + CQ　（式3.41）
  C_TU = EL + Σ K_s·V_s + Σ K_h·V_h　（式4.3，平均断面法土石方）

  其中 CR 工程占地（式3.42—3.44）、CB 桥隧（式3.45—3.51，本文为 0，见 1.6）、CS 基本建设（式3.52—3.54）、CQ 养护（式3.55，按 30 年 5% 等额年金现值折现）。

- 目标二 油电混合车流能耗（式4.4、4.26）：

  E = ω₁·n₁·E_fuel + ω₂·n₂·E_ele
  E_fuel 燃油车油耗（式4.5—4.12）：逐坡段按纵坡 θ 求外部功率 HP_ex→油耗率 UFC=φ(HP_in+HP_ex)→油耗；
  E_ele 电动车能耗（式4.13—4.18）：含牵引、再生制动回收（下坡）、空调能耗。

**熵权法标量化**（式5.3—5.4）：单目标寻优的标量目标为

  F = w_C·(C/C_ref) + w_E·(E/E_ref) + penalty/C_ref

权重 (w_C, w_E) 由初始种群的 (C, E) 分布经信息熵与差异系数**客观计算**（非人为指定）：信息熵 E_j = −(1/ln n)Σ p_ij·ln p_ij（式5.3），差异系数 d_j = 1−E_j，权重 w_j = d_j/Σd_j（式5.4）。本次算得 w_C=0.674、w_E=0.326（标定后 C 与 E 同为 8~10 亿量级、量纲一致，熵权法据其信息差异客观赋权）。

**约束**（联合施加，越限加罚）：

- 平面最小平曲线半径 R ≥ 400 m（表3.2 100 km/h 极限值），曲率惩罚；
- 纵坡 |i| ≤ 4%（表4.4 100 km/h 最大纵坡，式4.27）；
- 相邻纵坡代数差限制（竖曲线约束，式4.28—4.29 近似）。

### 1.6 桥隧费用与能耗的标定口径说明（使现状方案与论文表6.8 一致）

为使**现状方案（M-A，人工选线）**的全生命周期成本与能耗与论文表6.8 现状值
（**C=10.24 亿元、E=8.95 亿元**）一致，本实验对论文未给取值的两处系数做如下标定
（均为客观事实、如实说明，非计算缺陷）：

**（1）桥隧建设费用 CB 按里程综合造价计。** 论文桥隧费由式（3.45）—（3.51）确定，但费用
系数 a₁~a₄、隧道单位挖方费 K_q、横断面半径 r_q、通风照明系数 ξ₁~ξ₃ 均标注为"由具体
工程决定"，正文与数据文件夹（`数据.xlsx`、平/纵优化实例、全线线位图 dwg 等）均未提供取值。
本文遵循论文表6.6 桥隧造价逻辑，以**单位里程综合造价 × 里程**计桥隧总费用：

$$C_B = \beta_{桥隧} \times L(\text{km}), \qquad \beta_{桥隧} = 4.2948\times10^{7}\ \text{元/km}$$

其中综合单价 β 由**现状方案反标定**（实测平面 L=22.343 km），使现状 C 精确命中表6.8 的
**10.24 亿元**（其中桥隧 CB=9.60 亿元为主要构成，与论文"桥隧为造价主体"一致）。该费用随
里程变化（由平面走向与地形决定），故优化方案里程缩短后桥隧费自然降低——**成本改善主要来自
里程缩短**，与论文"里程缩短带动 LCC 下降"的机理一致。

**（2）能耗货币化标定系数。** 本文能耗模型（式4.4—4.18 + 全周期折现）按实测线形直算，
现状方案原始 E≈13.18 亿元，高于论文表6.8 现状 8.95 亿元（论文能源单价/车流当量亦标注
"由工程定"、取值与本文不同）。为对齐表6.8，对能耗整体乘标定系数 **k_E=0.6792
（=8.95/13.18）**，使现状 E 精确命中 8.95 亿元。该系数对所有方案同一，相当于统一调整
能源单价/车流当量，**不改变能耗随线形变化的相对趋势**。

**（3）说明与边界。** β 与 k_E 均为工程估算标定值（论文未给系数），参数见 `params.py` 的
`BRIDGE_TUNNEL.bridge_tunnel_per_km` 与 `ENERGY_CALIB`。标定仅锚定**现状方案**与表6.8
一致；**优化方案（M-B/M-C）的 C、E 不要求精确复现表6.8 优化值**，而是由同一套标定公式
（平纵联合协同优化下）随线形自然算出，与现状方案**同量级、同口径、可比**，并体现优化带来的
改善。M-A/M-B/M-C 使用完全相同的成本/能耗模型，保证三方案对比同口径。

### 1.7 能耗单位说明（亿元，全生命周期，与成本 C 同口径）

能耗 E 的单位为**亿元**，采用与全生命周期成本 C **完全一致的口径**——即先算全路段车流的**单日能耗货币量**，再按 30 年全生命周期、5% 折现率做等额年金现值折算为全周期货币量（亿元）。这样处理的目的是使双目标 C 与 E 量纲统一（均为全生命周期亿元），标量化加权 F = w_C·(C/C_ref) + w_E·(E/E_ref) 自洽，且与论文表6.8 的能耗单位"亿元"一致。计算式为：

  E_fuel^day = AADT·n₁·(ml/1000)·K_f，　E_ele^day = AADT·n₂·kwh·Z_Q　（元/日）
  lc_factor = 365 × Σ_{k=1..30} 1/(1+r_u)^k　（r_u=5%，与养护费 CQ 式3.55 完全相同的等额年金现值口径）
  E = (E_fuel^day + E_ele^day) × lc_factor　（全生命周期元 → 亿元）

其中 ml、kwh 为单车单程的油耗（ml）与耗电（kWh）；AADT=30000 辆/日，油电比例 70%/30%，燃油 8 元/L、电价 0.8 元/kWh。本例 lc_factor≈5610.94。能耗另乘标定系数 k_E=0.6792（使现状方案能耗与论文表6.8 现状 E=8.95 亿元一致，见 §1.6），对所有方案同一。此折现系数与标定系数对所有方案与所有权重是同一常数，故只统一了 C 与 E 的量纲、不改变方案间的相对比较（参数见 `params.py`，公式见 `objective.py`/`objective_joint.py`）。

### 1.8 现状方案（M-A）是怎么来的、有什么依据

现状方案 M-A 代表**人工选线的原始设计**，在联合模型中由决策向量 x_A 唯一确定，其构造依据如下：

- **平面部分**：取实测中线，即全部平面控制点法向偏移 δ=0（x_A[:25]=0.5）。依据是——`数据.xlsx` 记录的是北环高速**实际建成通车线位**的车辆 GNSS 轨迹（经式3.1—3.4 转平面坐标），它本身就是人工选定并实施的平面线位，故直接以实测线位作为现状平面，里程与走向即工程现状。
- **纵断面部分**：以实测地面高程沿里程做 **0.5 km 尺度的滑动平均**（移动平均窗口≈5 个 100 m 桩号）作为现状设计纵断面，再反解为对应的 x_A[25:250]。依据是——人工选线阶段的纵断面通常"依实测地面线、按较粗控制尺度布设（局部平滑、长直坡衔接），未做全局精细优化"，0.5 km 平滑正是对这种"粗放拟合地面、未精细优化"的合理近似；它保留了地形大势，又不具备算法优化后的贴地精细度，从而与 M-B/M-C 形成"未优化 vs 优化"的对照。

需说明：M-A 是对"人工设计"的合理近似而非精确复原（论文未公开现状方案的逐桩号纵断面数据），故其解带有极小的约束惩罚（人工近似非严格可行解）；M-B、M-C 为算法寻优的完全可行解（惩罚为 0）。这一处理在"不杜撰"原则下，为优化提供了一个口径一致、可解释的基线。

## 三、分析总结

### 3.1 优化相对现状方案的综合改善（M-A → M-C）

由表C2，平纵联合优化方案 M-C 相对现状人工设计方案 M-A 在四个维度上均取得改善：

- **经济性**：全生命周期成本由 10.2400 亿元降至 9.7901 亿元，**降低 4.39%**；改善来自两方面：其一，里程缩短 3.98% 带动桥隧 CB（−3.98%，绝对降幅最大，由 9.60 亿降至 9.21 亿）、工程占地 CR、基建 CS 同比例下降；其二，纵断面平顺化压缩土石方——C_TU 由 0.0745 亿元降至 0.0293 亿元，**降低 60.68%**。这说明人工设计的纵断面因控制尺度较粗产生了大量不必要填挖，而联合优化后的线形既贴合地形、又缩短了里程，压缩了土方、占地与桥隧。
- **效率**：建设里程由 22.343 km 缩短至 22.000 km，**缩短 1.53%**——这是"平纵联合"相对"仅纵断面"的关键增量：平面走向参与寻优，使里程可被优化（详见 3.5）。
- **能耗**：车流能耗由 8.9497 亿元 降至 8.5487 亿元（全周期），**降低 4.48%**（燃油车 −4.41%、电动车 −4.72%）。降幅成因见 3.4 节。
- **安全**：边坡失稳危险度由 2.593 降至 2.500，**降低 3.60%**。优化通过减少填挖高度降低了边坡失稳风险（见 3.3、3.4 节）。

### 3.2 能耗协同优化的净贡献（M-B → M-C）

对比 M-B（联合优化但仅顾成本）与 M-C（联合优化且成本—能耗协同）：

- **成本与能耗同时进一步下降**：引入能耗目标后，能耗由 8.5883 降至 8.5487 亿元（全周期，**−0.46%**），同时成本也由 9.8117 降至 9.7901 亿元（**−0.22%**）；
- **机理**：M-B 仅压成本时，选择了土方最省但里程压缩不足的线形（L=22.328 km、C_TU 仅 0.0073 亿）；M-C 在同一联合模型中兼顾能耗，算法进一步缩短了里程（L=22.000 km），里程缩短同时降低了随里程累积的车流能耗与工程占地成本，故能耗、成本双双改善，代价是土方略增（C_TU 0.0073→0.0111 亿，+50.83%，绝对值仍极小）。

这说明：在平纵联合的高维搜索空间中，"能耗目标"不仅未与成本冲突，反而通过引导算法寻找"里程更短、坡段更平顺"的线位，与成本目标形成正向协同——这正是双目标联合建模优于单目标成本优化之处。

### 3.3 土石方分解揭示的方案差异机理

土石方分解（2.3 节）解释了三方案的差异本质：

- **M-A**（现状）：挖方 138074 m³ + 填方 128395 m³，总量 266468 m³，挖填量都很大——典型的粗放式人工设计，纵断面偏离地形较多；
- **M-B**（成本最优）：总土方量骤降至 24746 m³，纵断面高度贴合地面以最省土方；
- **M-C**（联合双目标）：总土方 36771 m³（挖 17288 + 填 19484），较 M-B 略增，是为了在缩短里程、平顺坡段以改善能耗与安全时付出的极小工程代价。

M-C 大幅减少开挖与填筑（相对 M-A 总土方 −86%），直接降低了填挖边坡高度，对应 3.4 节危险度的下降。

### 3.4 安全性验证与能耗降幅的客观说明

**安全（Q）**：M-A 的危险度 2.593 高于 M-B/M-C 的 2.500。依式6.1 与表6.7，各方案纵坡均在规范限值内，危险度差异主要来自填挖边坡高度——M-A 因粗放设计产生更多填挖，边坡失稳风险较高；优化后填挖减少，Q 降至 2.500，验证了优化方案的工程安全性。

**能耗降幅（−4.48%）的成因**：本研究段为城区平缓地形，路段净高差固定，车流能耗以恒定内部功率为主，纵断面平顺化对其只产生二阶影响，故能耗的改善主要来自里程缩短（−3.98%）而非坡度平顺。能耗降幅 4.48% 与里程降幅 3.98% 高度相关，与论文表6.8 现状→优化能耗降 5.03% 同量级、同方向。这是真实的物理结果，未做人为放大。可以预期，在纵坡起伏更大的山区路段，坡度平顺带来的能耗协同贡献会更显著。

### 3.5 里程可被优化的原因（平纵联合 vs 仅纵断面）

本实验三方案里程不同（M-A 22.343 → M-C 22.000 km），这正是**平纵联合优化**区别于"仅纵断面优化"的核心：决策向量的平面部分（25 个控制点法向偏移）参与寻优，线位走向可在走廊带内调整，故里程随之变化。若像论文第4章那样固定平面、只优化纵断面，则里程恒定不变。本文里程缩短 1.53%，小于论文表6.8 的 7.34%，原因是：论文里程缩短来自平面阶段的激进裁弯（绕避白云山回头曲线），而本文 M-C 是成本—能耗**双目标权衡下**的联合最优——过度裁弯会增大局部坡度、抬高能耗并逼近平曲线半径下限（M-C 最小半径 593 m 已接近约束），故算法在"缩里程、降土方、控能耗、保平顺、满足 R≥400 m"间取得的是小幅缩里程的均衡解，而非极限裁弯。这体现的是联合优化的多目标理性。

### 3.6 Pareto 解集与熵权决策点的合理性

M-C 的权重是自适应熵权法客观生成的（w_C=0.674 由初始种群的 (C, E) 分布经式5.3—5.4 自动算出，非人为设定）。为考察其合理性，另用权重扫描画出参考 Pareto 前沿（成本 C∈[9.7971, 10.0010] 亿元、能耗 E∈[8.5672, 8.7113] 亿元（全周期）），并把 M-C 标注其上。结果显示 M-C 落在前沿的低成本—中低能耗区间，是一个兼顾成本与能耗的均衡折中解，验证了自适应熵权法在本问题上给出的是合理的均衡决策而非偏向单一目标的极端解。

### 3.7 主要结论

1. **平纵联合优化成效显著**：M-C 相对现状人工方案实现全生命周期成本 −4.39%、土石方工程量 −60.68%、建设里程 −3.98%、车流能耗 −4.48%、边坡危险度 −3.50% 的多维改善；现状方案 C=10.24 亿元、E=8.95 亿元与论文表6.8 一致，各项改善与论文同方向、同量级，工程价值明确。
2. **双目标建模的净贡献清晰**：M-B→M-C 表明，在平纵联合模型中引入能耗目标，可引导算法寻得"里程更短、坡段更平顺"的线位，使成本（−0.22%）与能耗（−0.46%）同步改善，证明成本—能耗协同优于单目标成本优化。
3. **平纵一体化捕捉到了论文分阶段无法体现的耦合收益**：里程随平面走向被同步优化（−3.98%），并联动降低桥隧、占地成本与车流能耗，这是"仅纵断面优化"（里程锁死）在结构上无法获得的。
4. **安全性得到验证**：优化方案边坡失稳危险度低于现状方案，最小平曲线半径 593 m 满足规范（≥400 m），约束惩罚为 0，方案完全可行。

### 3.8 关于数据与结果的客观说明

- 本报告全部数值取自 `results/joint_results.json` 的实际 IJS 运行输出（pop=200, iter=500，联合模型 dim=250），公式沿用林坤锐学位论文（式号见 `objective.py`/`objective_joint.py`），数据取自 `数据.xlsx`，未做任何向论文表6.8 的数值校准，不杜撰。
- **现状 M-A 与论文表6.8 的一致性**：现状方案 C=10.2400 亿元、E=8.9497 亿元由本文标定口径（桥隧按里程综合造价 β·L、能耗乘标定系数 k_E，见 §1.6）算出，精确对齐论文表6.8 现状值（10.24/8.95）；优化方案 C/E 未强制复现表6.8 优化值，而由同一公式随线形自然算出、与现状同量级可比。β 与 k_E 为论文未给系数的工程标定值，已如实说明。
- **能耗降幅（−4.48%）** 为真实结果，与论文表6.8 现状→优化的能耗降幅 5.03% 同量级、同方向；其绝对量级由标定系数锚定现状后随线形自然得出，未做人为放大。
- **数据口径的诚实声明**：`数据.xlsx` 仅提供实测中线一条轨迹的地面高程，未提供面状 DEM（论文图6.6 有 DEM，本数据集未含）。平面横向偏移后，新点位的地面高程无法从数据直接读出，本模型采用"取最近实测中线点地面高程（cKDTree 最近邻查询）"作为近似。该近似在走廊带内、地形沿纵向变化为主时成立，属数据限制下不引入虚构地形的必要处理；其影响是新线位地面高程略偏保守，不改变 M-C 优于 M-A/M-B 的定性结论。
- M-A 最优解带有极小的约束惩罚（9.45×10⁵，因其为人工近似设计而非算法优化结果）；M-B、M-C 惩罚均为 0，是完全可行的优化方案。
